# Little Lemon — Database Engineer Capstone

## Project Overview

This repository contains the **Little Lemon Database Engineer Capstone Project** from the Coursera Professional Certificate.

The project demonstrates the design and implementation of a restaurant database solution, including database modelling, sales reporting, table booking, data analysis, visualization, and a Python database client.

## Project Objectives

- Design and implement a relational database for Little Lemon.
- Create an ER data model using database modelling concepts.
- Develop SQL queries, reports, and booking procedures.
- Analyze sales data and create visualizations.
- Build a Python client to interact with the database.
- Apply Git version control and branching throughout the project.

## Main Deliverables

1. Database setup and ER diagram.
2. Sales reports and optimized SQL queries.
3. Table booking system.
4. Tableau sales and profit dashboard.
5. Python database client with query functions.
6. Git-based version control and project documentation.

## Technologies & Tools

- **MySQL / MySQL Workbench** — database development and SQL.
- **Python** — database client and query functions.
- **VS Code** — development environment.
- **Git / Git Bash** — version control, branching, and project history.
- **Tableau** — data visualization and dashboarding.
- **Data Modelling** — ER diagrams, relationships, keys, and relational database design.

## Project Structure

The repository will be organized by project phase/module, with SQL scripts, database models, Python client code, visualization resources, and supporting documentation maintained under version control.
